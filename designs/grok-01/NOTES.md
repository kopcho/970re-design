# grok-01 — Listing Detail

## Type
- **Display / price / quotes:** Iowan Old Style → Palatino → Georgia (serif). Confident, editorial, Northern Colorado newspaper energy. Numbers and agent quotes live here.
- **UI / labels / mono:** system UI stack + `ui-monospace` for evidence tags, counts, and the strict lock language. Keeps the precision feel from the sculpt/hunt models without competing with the serif.

## Palette
Evolved from the forest system in `/models` — same DNA, pushed into daylight for the detail screen (where people actually *read*).

| Token | Value | Role |
|-------|-------|------|
| `--ink` | `#0E2A1B` | Primary text, deep forest |
| `--paper` | `#F7F4EC` | Page background (warm bone) |
| `--surface` | `#FFFFFF` | Cards |
| `--gold` | `#C79A3E` | Confirmed evidence, CTAs |
| `--gold-soft` | `#D8B25E` | Hover / secondary gold |
| `--assert` | `#1F7A3D` | ✓ confirmed |
| `--potential` | `#B8860B` | ~ possible (amber, quieter) |
| `--mist` | `rgba(14,42,27,.55)` | Secondary text |
| `--line` | `rgba(14,42,27,.10)` | Hairlines |
| `--spark` | `#E85D04` | Re970 signature action (Front Range sunset / urgency) |

## Why this direction
1. **Evidence is the product.** The quotes had to feel like proof, not decoration. Large italic serif + green ✓ badge makes the agent’s words un-ignorable.
2. **Daylight readability.** Detail screens are long. Warm paper + dark ink beats pure dark mode for scanning photos + reading remarks.
3. **Continuity without copy.** Same forest/gold DNA as the refine prototypes so the system still feels like one product, but the listing is allowed to breathe and feel premium.
4. **Re970 as signature.** Burnt-orange spark color + bold “Re970” label gives the parcel action the presence the brief asked for — it is not just another icon.
5. **No drift, no lies.** Confirmed vs possible is visually distinct (green vs amber). Missing gems are simply absent — never shown as “no.”
