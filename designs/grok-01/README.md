# grok-01 — first design pass

Your canvas. Read [`/BRIEF.md`](../../BRIEF.md) first, play the two prototypes in [`/models/`](../../models), and build against [`/reference/fixture-ai-search.json`](../../reference/fixture-ai-search.json) (real data with gems + verbatim quotes).

## Suggested first move
Design **one screen end-to-end** to set the visual language. Recommend the **listing detail** — it's where the moat lives (the *exact-match* + the agent's *verbatim quote*). Nail that one and the rest of the system falls out of it. (The prior renders in `/reference/grok-render-*.jpg` are a decent start — push past them.)

## Drop your work here
- Screens as images (`opening.png`, `results.png`, `refine.png`, `listing.png`, `map.png`, `re970-parcel.png`) and/or clickable HTML.
- A short `NOTES.md`: the type + palette you chose, and why.

## What a great pass hits
- [ ] **Opening** — sparse, search-first, one clear action.
- [ ] **Results** — evidence cards + best-matches/rest split + an **honest count**; a map peek.
- [ ] **Refine** — your take on the *sculpt* or the *hunt* (see `/models`). **Not** a 25-item filter form.
- [ ] **Listing** — photos + the exact-match + the **quoted** evidence + talk-to-Rich.
- [ ] **Map** — price dots that cluster + draw-an-area.
- [ ] **Re970 parcel** — the drive-by moat (satellite + lot lines over the trees + the gated "Agent only" owner block). Make it a **signature action**.
- [ ] It reads as **970.re / Northern Colorado / Rich** — not a generic portal.

The look is entirely yours. The only fixed stars are in `/BRIEF.md`. Surprise us.
